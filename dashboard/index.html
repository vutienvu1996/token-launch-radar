How implied value is computed

Every row is scored by one function of the snapshot figures. No protocol name is special-cased. The board fits a log-size curve on the snapshot's own traded tokens, then adjusts each protocol by its family multiplier, seven-day growth and time with no token. Formula, fit and backtest are on the board above.

What this board cannot know

  • No token is confirmed for any row. The snapshot records no token; a launch may never happen, and no points program is recorded either. Farm the usage, not a promised airdrop.
  • Backers are not in the snapshot. This board makes no claim about who funded a protocol.
  • Implied value is a model, not a price. It ranks protocols against each other; it does not predict a listing price. Leave-one-out median miss is 2.82x: treat any single row as order-of-magnitude.
  • The snapshot is frozen at 2026-11-14. A protocol that launched, collapsed or changed after that date still shows as it stood then.
