How implied value is computed

Every row is scored by one function of the snapshot figures. No protocol name is special-cased, and no row is hand-picked. A dollar of TVL is not worth the same in every category, and the snapshot itself says so: each category's multiple is the median market-cap-to-TVL ratio of that category's tokens that already trade, read off this same snapshot, shrunk toward the market median when the category has few live tokens, and capped at 1.00x TVL.

implied = round( tvl_usd x category multiple x (1 + clamp(change_7d, -50, 100) / 100 x 0.35) x (0.65 + min(age_days, 1095) / 1095 x 0.35) )

Category multiple = (n x median + 5 x 0.246) / (n + 5), clamped to 0.05x–1.00x. 0.246x is the median market-cap-to-TVL ratio of all 119 live-token protocols in the snapshot. A category with no live token uses 0.246x. Age is the time since the protocol was first listed, the best record of how long it has run with no token; an unlisted age uses 365 days. Seven-day growth is dampened on purpose: a hot week moves the value by at most a third of its size.

Comparables by category

Live tokens only, from this snapshot. Thin categories are pulled toward the market median, so a single live token can never set a category's multiple on its own. What this board cannot know

  • No token is confirmed for any row. The snapshot records no token for these protocols; a launch may never happen, and a points program is not recorded either. Farm the usage, not a promised airdrop.
  • Backers are not in the snapshot. This board makes no claim about who funded a protocol. Do not trust a backer claim unless the protocol or the fund publishes it.
  • Implied value is a model, not a price. It is a way to rank protocols against each other, not a prediction of what a token would list at. TVL can leave, growth can reverse, and a category's multiple is only as good as its live tokens.
  • The snapshot is frozen at 2026-11-14. A protocol that launched, collapsed or changed after that date still shows here as it stood then.
